# Archiwum workflowów

Ten katalog zawiera wcześniejsze jednoplikowe workflowy aplikacji „Zgłoś obrączkę”. Zostały przeniesione poza `.github/workflows`, aby kolejne zmiany nie uruchamiały równocześnie wielu przestarzałych buildów.

Aktywnym workflowem wydania jest `.github/workflows/release-google-play.yml`.
