# Aplikacje - zmaterializowane źródła

Ten katalog zawiera normalne, przeglądalne źródła aplikacji, które wcześniej były przechowywane głównie jako ZIP-y albo generowane wewnątrz workflow GitHub Actions.

- `zglos-obraczke` - aplikacja Android do zgłaszania zaobrączkowanych ptaków.
- `ptasie-budki` - aplikacja Flutter/Supabase do budek lęgowych.
- `ptasie-obserwacje` - aplikacja Flutter/Supabase do obserwacji ptaków.
- `grunwald` - aplikacja Flutter Grunwald 2026.
- `lowca-mieszkan` - aplikacja Flutter Łowca Mieszkań V4.

Źródłem prawdy po przeglądzie powinny być katalogi `apps/*`, a nie archiwa ZIP ani kod osadzony w plikach workflow.
