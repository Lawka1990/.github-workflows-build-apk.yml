# Jak pobrać APK

1. Wgraj cały projekt do repozytorium GitHub.
2. Otwórz zakładkę **Actions**.
3. Wybierz **Build Łowca Mieszkań V4**.
4. Kliknij **Run workflow**.
5. Po zakończeniu pobierz artefakt **lowca-mieszkan-v4-android**.
6. W archiwum znajdziesz `app-release.apk` do instalacji oraz
   `app-release.aab` do dalszej publikacji.

Workflow sam tworzy brakujące pliki Androida, uruchamia testy i dodaje aplikację
do systemowego menu **Udostępnij**.
